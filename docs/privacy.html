Privacy Policy

Effective October 10, 2026

gphoto-sync is open-source software (MIT License) that you install and run on your own computer. Northern Captain publishes the software but does not operate it for you: there is no hosted service, no account with us, and no server of ours that your data passes through. This policy explains what the software does with your data when you run it, and what this website collects.

What the software accesses

When you connect a Google account, gphoto-sync asks for access to Google Drive through Google's OAuth consent flow, using an OAuth client that belongs to your own Google Cloud project. The permission requested is full access to your Google Drive (the drive scope): Google offers no narrower permission that lets a tool download files created by Takeout and delete them afterwards. What the software does with that permission is limited to the following:

  • lists the folder in your Drive where Google Takeout places its export archives;
  • downloads those archive files to your computer;
  • when you enable the option, moves and deletes an archive from your Drive after it has been safely stored locally.

It does not read, change or share any other file in your Drive, and it does not use the Google Photos API. You can see exactly what it does in the source code, and you can withdraw the permission at any time (see below).

Where your data goes

  • Your photos and videos are extracted from the archives into a folder tree on a disk you choose, on your own machine.
  • Metadata exported by Takeout (dates, descriptions, album names, location data if you include it) is stored next to the files and in a local SQLite database on the same machine.
  • The OAuth token that grants Drive access is stored in rclone's configuration file on your machine, readable only by the user that runs the software.
  • Reports about each run are the one optional exception. If you create a Telegram bot and pair a chat with it, the software sends a short report after each run (archive and file names, counts, error messages; never the photos or videos themselves) through Telegram's servers to the chats you paired. Nothing is sent if you do not configure a bot.

None of this is transmitted to Northern Captain, and apart from the optional Telegram reports nothing is transmitted to any third party. The software has no analytics, telemetry or crash reporting.

What we collect

Nothing. We do not receive, store or have access to your photos, your metadata, your Google account or your access tokens. This website is a set of static pages: it sets no cookies and runs no tracking scripts. It is hosted on GitHub Pages, whose own privacy practices are described in GitHub's privacy statement.

Google user data

gphoto-sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the backup function described above, is never sold and never used for advertising. It is stored on the machine you run the software on and is not shared with anyone, except for the information contained in the optional run reports (file names and counts, never the media) that you can choose to have sent to your own Telegram chats.

Revoking access

You can withdraw the software's access to your Google account at any time at myaccount.google.com/permissions, by removing the application there. Deleting the remote's section from your rclone configuration file removes the stored token from your machine. Your local copy of the library is yours to keep or delete.

Children

The software and this website are not directed at children under 13 and do not knowingly collect information from them.

Changes

If this policy changes, the new version will be published on this page with an updated effective date. The history of changes is visible in the project's public repository.

Contact

Questions about this policy can be raised by opening an issue at github.com/NorthernCaptain/gphoto-sync/issues.
